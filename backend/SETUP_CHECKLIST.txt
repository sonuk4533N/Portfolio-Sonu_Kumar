1️⃣  FOR GMAIL USERS:
    
    □ Go to: https://myaccount.google.com/apppasswords
    □ Select "Mail" and "Windows Computer" 
    □ Copy the 16-character password
    □ Open: backend/.env
    □ Update line 9:  EMAIL_USER=your_email@gmail.com
    □ Update line 10: EMAIL_PASS=xxxx xxxx xxxx xxxx  (paste password, remove spaces)
    □ Update line 11: EMAIL_FROM=your_email@gmail.com
    □ Update line 12: RECIPIENT_EMAIL=your_email@gmail.com

2️⃣  INSTALL DEPENDENCIES:
    
    □ Open terminal in backend/ folder
    □ Run: npm install
    
3️⃣  START THE SERVER:
    
    □ Run: npm start
    □ You should see: ✓ Server running on http://localhost:5000

4️⃣  TEST THE FORM:
    
    □ Fill out contact form on website
    □ You should receive 2 emails:
       - Email 1: Admin notification
       - Email 2: Confirmation to sender
    □ Check spam folder if not found

Problem: "Authentication failed"
→ Check email/password are correct in .env
→ Make sure you used App Password, not regular password

Problem: "Emails not arriving"  
→ Check spam/junk folder
→ Verify RECIPIENT_EMAIL is correct in .env
→ Check backend console for error messages

Problem: "npm install fails"
→ Make sure you're in the backend/ folder
→ Delete node_modules and package-lock.json, try again

Problem: "Server won't start"
→ Check if port 5000 is already in use
→ Change PORT in .env if needed
